# 手机版 / 车机版 1.2.43

- 本版包含若干功能调整与问题修复。
- 覆盖升级后歌单、收藏、播放统计、歌词设置全部保留，曲库缓存自动复用，无需重新扫描。

**适用设备**：Android 7.0（API 24）及以上；手机与车机通用（车机横屏界面自动切换）。

**安装**：按设备架构下载对应的包，直接覆盖安装即可：

| 安装包 | 适用设备 |
| --- | --- |
| `WindTone-v1.2.43-arm64-v8a.apk` | 绝大多数手机 / 车机 |
| `WindTone-v1.2.43-armeabi-v7a.apk` | 较老的 32 位设备 |
| `WindTone-v1.2.43-x86_64.apk` | 模拟器 / ChromeOS |
| `WindTone-v1.2.43-universal.apk` | 不确定架构时选它 |

**升级**：也可以在应用内「设置 → 更新 → 检查更新」一键升级（安装包由 GitHub 上的公共分发仓库提供，直连不通时会自动切换镜像线路）。

**隐私**：音频与歌词只在本机读写；联网只有一处——检查/下载更新（GitHub 公共分发仓库）。不采集、不上传任何信息。
